# 🐞 SnapDebug  
### Your Code's Fastest Path to Clarity 

---

## 🚀 Overview  
SnapDebug is a lightweight AI-powered debugging tool that helps you quickly understand and fix coding errors.  
Just upload a screenshot of an error or paste your code, and get structured debugging insights instantly.

No setup. No digging through forums. Just answers with clarity.

---

## ✨ Features  

- 📸 **Screenshot Debugging**  
  Upload error screenshots and let AI analyze them  

- 🧾 **Paste Code / Error Support**  
  Works with raw code or stack traces  

- 🧠 **Structured Output**  
  - Error  
  - Cause  
  - Fix  
  - Code (optional)  

- 🎯 **Hints or Full Solution Mode**  
  Choose how much help you want  

- 🌐 **Language Selection**  
  Improve accuracy with context (Python, C++, JavaScript, etc.)

- 📋 **One-Click Code Copy**  
  Easily copy corrected code  

- 🎨 **Modern UI**  
  Clean, dark-themed interface with sidebar workflow  

## 🧠 How It Works
1. Upload a screenshot or paste code
2.  Input is sent to the Gemini model
3. AI analyzes the error
4. Structured response is generated
5. Results are displayed in clean sections[Error,Cause,Fix,Solution Code]

## 🔮 Future Improvements
1. OCR fallback for better screenshot parsing
2.  Chat-based follow-up debugging
3. Code diff highlighting
